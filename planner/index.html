        Connect Google Drive (one time)

        In the same Google Cloud project you used for the phone's Drive sync:

        1. Open console.cloud.google.com → project Air Pilot → Google Auth Platform → Clients → Create client.
        2. Application type: Web application. Name: Air Pilot Planner.
        3. Under Authorized JavaScript origins add https://uberwulf.github.io (no slash at the end). Leave redirect URIs empty.
        4. Click Create and copy the Client ID (ends in .apps.googleusercontent.com).
